# ML-Practice

Machine Learning practice repository featuring predictive maintenance modeling and exploratory data analysis.

## Overview
This repository contains experiments and practice implementations for predicting the **Remaining Useful Life (RUL)** of industrial machines based on sensor readings, operational shifts, and machine types.

## Repository Structure
- `machine_remaining_useful_life.csv`: Dataset with sensor telemetry (`Sensor_1` through `Sensor_5`), machine metadata (`Machine_Type`, `Shift`), and target remaining useful life (`Remaining_Useful_Life_Hours`).
- `practice.ipynb`: Jupyter notebook containing exploratory data analysis (EDA), data preprocessing, feature engineering, and predictive modeling.
- `.gitignore`: Standard git ignore rules for Python and Jupyter environments.
